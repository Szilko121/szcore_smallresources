# szcore_smallresources

**SzCore Framework 1.4.0-rc1** · by **SzCode**

Small gameplay/QoL systems: crouch, cruise control, no-seat-shuffle, recoil, stun tuning, tackle, vehicle push/flip, weapon draw animation, utility ammo, consumable effects and configurable teleports.

Dependencies: `szcore`, `szcore_inventory`, `szcore_ui`.

Key mappings:
- LCTRL — crouch
- K — cruise
- G — tackle
- LSHIFT — vehicle push
